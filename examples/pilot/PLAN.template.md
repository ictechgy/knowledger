# 채택 파일럿 계획과 결과

상태: 준비 중. 빈 항목을 참여 조직과 합의한 뒤 시작한다. 이 템플릿은 실제 도입
결과가 아니며, 작성본·관찰 로그·측정 아티팩트는 조직의 비공개 저장소에 보관한다.
[실행 안내](../../docs/28-ADOPTION-PILOT.md)를 함께 사용한다.

## 시작 전에 고정할 범위

| 항목 | 합의한 값 |
| --- | --- |
| pilot_id / 담당 maintainer | 미정 |
| 측정할 개념 / 실제 업무 하나 | 미정 |
| 참여 조직 / context / 전체 acceptance slot | 미정 |
| 사람 검토자·필수 승인 역할 | 미정 |
| 시작·종료 시각 / 회고일 | 미정 |
| 배포 커밋 / Node / 어댑터 / 채널 | 미정 |
| 저널·private 저장 경계 / 운영·복원 담당 | 미정 |
| 공유할 문서 / 공유에서 제외할 자료 | 미정 |
| SSO·signer / 모델 egress 허용 범위 | 미정 |
| 비교 대상 업무·문서 수 / 성공·중단 기준 | 미정 |

공유 본문은 채널 인프라 운영자에게 보이고 과거 사본을 회수할 수 있다는 점을
참여자가 확인한다. 조직·역할은 해당 파일럿 설정으로 정한다. 예제 부서 구성을
제품 기본값으로 사용하지 않는다. AI는 초안을 만들 수 있으나 사람 승인을 대신하지 않는다.

## 비교 설계

같은 업무와 비슷한 문서·검토 범위를 기존 중앙 KB/RAG + metadata governance
대조군과 Knowledger에서 관찰한다. 기간, 참여자 수, 완료 업무 수를 각각 기록한다.
순서에 따른 학습 효과, 난이도·문서량·참여자 차이는 회고에 남긴다.
관찰이 없었던 항목과 관찰했지만 사건이 0건인 항목을 구분한다.

| 지표 | 기존 절차 | Knowledger | 해석 / 성공 기준 |
| --- | --- | --- | --- |
| 해석 혼합 / 완료 업무 수 | 미측정 | 미측정 | 시작 전 정의 |
| 합의 소요 시간 / 표본 수 | 미측정 | 미측정 | 시작 전 정의 |
| 질문·재검토 / 완료 업무 수 | 미측정 | 미측정 | 시작 전 정의 |
| 공개 부담 / 관찰 범위 | 미측정 | 미측정 | 시작 전 정의 |
| 의존성 참조 개정 비율 | 미측정 | 미측정 | 구조적 재사용 지표 |
| 두 번째 실제 업무의 지식 재사용 | 미측정 | 미측정 | 관찰로 별도 확인 |
| 운영·검토 투입 시간 | 미측정 | 미측정 | 사람이 별도 기록 |

`review_effort`는 거래·질문 수이며 노동 시간 자체가 아니다. `reuse_rate`는
의존성 참조가 있는 개정 비율이며 실제 업무 성공률이 아니다. baseline에 원장이
없으면 동일 지표가 있는 것처럼 채우지 않고 수동 기록의 출처를 표시한다.

## 진행과 중단

1. 독립 파일럿 데이터와 관찰 로그를 준비하고 시작 시점·대상 문서를 기록한다.
2. 실제 사람이 초안 공개, 개정 검토, 승인·이의 제기를 수행하고 각 관찰을 기록한다.
3. 합의된 지식을 다른 업무에서 재사용하고 질문·해석 혼합·공개 부담을 관찰한다.
4. 인가 실패, 의도치 않은 공개, 잘못된 normative 제공 또는 사전 중단 기준 발생 시
   새 공개·사용을 중단하고 원장·초안·운영 근거를 보존한다. 이미 공유한 본문을
   삭제할 수 있다고 가정하지 않는다.
5. 측정 전 앱을 정상 종료한다. 오프라인 스냅샷과 새 디렉터리 복원본에서 검증된
   저널을 측정하고, 채널·window·관찰 digest를 기록한다.

## 종료 기록

- 실제 참여·기간·완료 업무 수: 미측정
- 배포 커밋·환경 및 측정 아티팩트 위치: 미정
- `window` 이벤트 범위·관찰 로그 digest, Fabric이면 `source` 전체 블록 tip·저널 digest: 미측정
- 사용 가능한 baseline / 비교할 수 없는 항목과 이유: 미정
- 해석 혼합·검토 수고·공개 부담·재사용·운영비 변화: 미측정
- 다음 결정(확대 / 조건부 반복 / 중단), 책임자와 이유: 미정

공개할 결과에는 키·토큰·개인정보·부서 비공개 내용·원문 질의를 넣지 않는다.
참여자가 검토한 집계와 검증 경계만 별도로 공개한다.
