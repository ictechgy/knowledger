# 내 요청: 미확정 거래 추적과 재시도

게시·제안·승인·활성화·철회 요청을 계정별로 추적한다. 요청 ID와 실행할 명령은 전송 전에
비공개 SQLite에 저장한다. 브라우저 새로고침이나 앱 재시작 후에도 같은 데이터 폴더에서 이어서 확인한다.
원문·승인 근거·인증정보를 브라우저 storage에 별도 저장하지 않는다.

## 상태의 의미

| 상태 | 의미 |
| --- | --- |
| 확인 중 | 요청 결과가 아직 확정되지 않음. ACK·timeout·SDK VALID만으로 완료를 표시하지 않음 |
| 미확정 · 확인 불가 | peer/API 상태를 확인하지 못함. 성공 또는 실패로 추정하지 않음 |
| 커밋 확인됨 | 원장의 idempotency record가 actor·명령 내용과 일치하며 정확한 거래 checkpoint를 확인함 |
| 거절됨 | 사전 권한/도메인 검사 또는 거래 검증이 거부함. 이후 발견한 원래 커밋 결과가 있으면 그 결과가 우선 |
| 취소됨 | 서명 경로에서 전송 전에 인가가 취소된 것으로 확인됨 |

로컬 시뮬레이션의 커밋은 SQLite 커밋이다. Fabric 실행의 커밋은 검증된 peer 블록과
projection의 원래 receipt가 필요하다. duplicate INVALID가 먼저 성공한 논리 명령을 실패로 뒤집지 않는다.

## 화면 동작

- 최근20개를 표시하고 더 보기로 이전 요청을 확인한다. 목록은 현재 actor만 볼 수 있다.
- 미확정 요청은 한 번에 최대3개씩 순서대로 확인한다. 간격은5초에서 최대30초까지 늘어나며
  숨겨진 탭에서는 멈춘다. 자동 확인은 새 거래를 제출하지 않는다.
- 같은 대상·같은 종류의 요청을 보내는 중이거나 이미 미확정이면 새 명령을 중복 생성하지 않도록 안내한다.
- **같은 요청 다시 보내기**는 서버에 저장된 원래 ID·본문·결정 시각을 재사용한다.
  새 승인이나 새 공개 확인을 만들어 기존 요청을 바꾸는 기능이 아니다.
- 재시도도 현재 계정·역할·정책·인가를 다시 검사한다. 활성화의 expected active ID도 바꾸지 않는다.
  정책이나 활성 상태가 바뀌어 거절됐다면 내용을 검토하고 새 요청을 작성해야 한다.
- 계정 전환·로그아웃 시 이력과 진행 상태를 비우고 이전 응답을 무시한다.
- 게시 응답이 유실돼도 요청 이력에서 원래 커밋을 확인하면 문서를 다시 읽는다.

## API

모든 경로는 `/v1/workspaces/{workspace.id}` 아래에 있다.

| 경로 | 결과 |
| --- | --- |
| `GET /commands?limit=20&cursor=...` | 본인 요청의 상태·종류·대상·생성일·다음 cursor |
| `GET /commands/{command_id}` | 한 요청의 상태와, 커밋 확인 시 checkpoint |
| `POST /commands/{command_id}/retry` | 빈 JSON `{}`로 원래 명령 재시도; CSRF·Origin·현재 인가 필요 |

목록 limit은1–50이다. 다른 actor의 ID/cursor는404다. 본문·rationale·서명 bytes·토큰은 반환하지 않는다.
GET은 ledger proposal/endorsement/submission을 만들지 않는다. 확인한 peer 블록과 거래 상태는
로컬 projection/outbox 관측 캐시에 반영될 수 있다.

한 detail 조회에서는 미확정 시도 하나만 peer에 질의한다. 하나의 논리 명령에128개를 넘는
시도가 있으면 전체 확인 없이 실패로 단정하지 않고 미확정을 유지한다.
추적 metadata가 없던 예전 명령도 원장 결과를 확인할 수 있지만 생성일은 알 수 없을 수 있다.

## 검증

`test/api/commands.test.ts`는 계정 격리·pagination·재시작·멱등 재시도·실패·원래 내용 비노출을 검사한다.
Fabric adapter 테스트는 상태 확인 중 재제출 금지와 SDK VALID만으로 성공하지 않는 경계를 검사한다.
실제 Fabric 확인은 `npm run configured:smoke`, 브라우저 회귀는 `npm run test:browser`로 실행한다.
