                  공유 개정 선택과 참조 조건

                      UTF-8 파일 한 개, 최대 256 KiB. 위 제목과 범위를 확인하세요. 현재 원문 대신 선택한 파일로 새 비공개 초안을 저장합니다. 공유하려면 별도 공개 검토가 필요합니다.

                      본문이 비어 있을 때만 적용합니다. 조직과 검토자는 선택한 정책을 따릅니다.

                      저장 전에는 공용 원장에 기록되지 않습니다.
